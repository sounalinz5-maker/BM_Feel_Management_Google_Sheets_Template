1. เชื่อม API ทดสอบผ่าน HTTPS

เมื่อมี API STAGING เปิดใช้งานแล้ว ให้ใส่ลิงก์ HTTPS ที่ได้รับจากผู้ดูแลระบบ ไม่ใช่ลิงก์ Apps Script เดิม

ยังไม่ได้เชื่อมต่อ API

หากยังไม่มีลิงก์ API แสดงว่าเซิร์ฟเวอร์ STAGING ยังไม่ถูก Deploy และไม่สามารถล็อกอินจริงได้
