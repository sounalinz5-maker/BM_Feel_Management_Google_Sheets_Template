วิธีติดตั้งแบบง่าย

เปิดหน้านี้ใน Google Chrome แล้วกดปุ่มติดตั้งด้านบน หรือกดเมนู Chrome (⋮) → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก จากนั้นเปิดไอคอน BM FUEL ที่หน้าจอโทรศัพท์

Android: เปิดลิงก์นี้ใน Chrome โดยตรง (ไม่ใช่หน้าต่าง Google Apps Script) → กด ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก

iPhone: เปิดใน Safari → แชร์ → Add to Home Screen / เพิ่มไปยังหน้าจอโฮม

หากมี BM FUEL แบบทางลัดเก่า ให้ลบทางลัดเก่าก่อนแล้วติดตั้งจากหน้านี้

ข้อมูลของคุณยังปลอดภัยในระบบเดิม

แอปที่ติดตั้งจาก GitHub Pages นี้เป็น ตัวเปิดระบบ (PWA Launcher) เท่านั้น ไม่มีข้อมูลลูกค้า รหัสผ่าน ยอดขาย หรือ Google Sheets อยู่ใน GitHub การกดเปิดระบบจริงจะไปยัง Google Apps Script ซึ่งอาจแสดงแถบแจ้งเตือนของ Google ตามปกติ
