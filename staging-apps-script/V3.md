# BM FUEL STAGING V3 — dashboard and calculated daily stock
- Same private Apps Script Web App; no Railway; exact STAGING sheet only.
- Daily meter rows are unchanged. Only closed readings count as sales, separately by fuel; incomplete days show provisional totals.
- Daily_Inputs_STAGING is created only on a confirmed sample input save; stores one row per date with fuel prices in whole LAK, opening stock and total received liters. Re-saving replaces that date's sample inputs after confirmation. No other tabs are changed. 
- Sales = closed liters × daily fuel price (rounded to nearest whole LAK per fuel); stock = opening + received − closed liters. Negative or above capacity values are flagged; never clamped. Diesel capacity 30,000 L; gasoline 20,000 L. No starting quantity or price is inferred. No automatic inventory carry-over, receipts ledger, historical price splits, actual tank gauge, or production dashboard connection yet.
